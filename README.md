# Hardwood Supply

Static basketball shop (HTML, CSS, JavaScript). No build step.

Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

- `index.html` page structure
- `styles.css` theme tokens (light and dark) and layout
- `script.js` product data, filters, cart, checkout

Orders are not sent anywhere; checkout is a front-end demo. To take real orders, add a backend in the `submit` handler in `script.js`.
